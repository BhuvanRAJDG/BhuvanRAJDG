# 🏆 Flagship Project

## 🤖 CBS Bot

### Core Banking System AI Assistant

> **Flask • GPT-4o • MySQL • ChromaDB • JWT • RAG • Tailwind CSS**

CBS Bot is an enterprise-grade **Core Banking System AI Assistant** designed to modernize digital banking through conversational AI. It combines secure banking operations with Retrieval-Augmented Generation (RAG), multilingual support, fraud intelligence, and role-based authentication to deliver intelligent, privacy-aware banking assistance.

### ✨ Key Highlights

* 🤖 GPT-4o powered conversational banking assistant
* 🔍 RAG with ChromaDB for RBI guidelines & banking policies
* 🔐 JWT + OTP + Role-Based Access Control (RBAC)
* 💳 Customer accounts, transactions, loans & EMI management
* 🛡️ Fraud alerts, audit logging & secure session handling
* 🌐 English • Kannada • Hindi multilingual support
* 📊 Premium fintech dashboard with Chart.js analytics
